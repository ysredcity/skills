# 设计系统：薄荷青绿 · 轻盈活力风格（Mint Vibe）

> 本文档是一套面向 AI Agent 优化的**移动端视觉风格**规范，提炼自一组清爽、年轻、活力的界面。它不绑定任何具体产品或品牌，仅表达一种可复用的设计语言。所有颜色均以直接 hex / rgb 色值给出，不依赖任何框架或 CSS 变量环境，便于在后续开发中直接约束生成相同风格的界面。

## 1. 视觉主题与氛围
「薄荷青绿」是一套轻盈、明快、有呼吸感的移动端视觉风格。整个体验建立在一层极浅的薰衣草灰画布（`#F3F2F7`）之上，纯白圆角卡片像漂浮的卡片一样铺陈其中，配合一抹**清浅、明度偏高**的薄荷绿（`#4FE0B5`）作为核心品牌信号色，并以**薰衣草紫**（`#9D8CF7`）作为辅助色。它刻意远离厚重、暗调、拟物的路线，转而追求清爽、留白、活泼的现代年轻感。


最具辨识度的动作有三个：其一是**分级大圆角与胶囊形态**——按钮、搜索框、标签用高度圆润的 pill 形，内容卡用 16–20px 大圆角，小元素（角标、缩略图、输入框方形场景）用 4–12px 的恰当小圆角。**注意：圆角是「分级」而非「一味全圆」**——遵循一套从小到大的圆角刻度（见 §6），让每个层级的元素用对应的圆角并保持同级一致，而不是把所有东西都做成最大圆角；小尺寸元素、贴边/通栏分隔、表格类密集信息等场景，恰当的小圆角甚至直边反而更利落清晰。其二是**Material 3 风格底部导航 + 液态玻璃悬浮材质**——底部导航采用 MD3 navigation bar 模式：实色容器表面 + 选中项用薄荷绿浅底「药丸」指示器（active indicator）包裹填充图标，选中态清晰可读；液态玻璃则作为**悬浮材质**用于状态切换胶囊等真正浮于内容之上的元素，营造苹果式的通透质感。其三是**克制的主题色 + 中性深灰的搭配**——薄荷绿只点在关键操作与强调处，其余动作、次要按钮交给深灰，使整个界面干净、聚焦、不喧闹。

色彩上采用「中性打底 + 绿色点睛 + 深灰承重」的策略：背景与卡片几乎全是无彩的浅灰与纯白，文字是接近纯黑的柔黑（`#1A1A1A`）与温和的中灰（`#8A8A8F`）。**主题绿是稀缺的点睛色，单页面内只在最关键的 1～2 个操作或强调处出现；其余的次要操作、普通按钮一律使用深灰**。这样主题色才有信号价值，界面也更显克制有质感。**另一条关键约束：薄荷绿明度高，其上的文字与图标一律使用深灰（`#1A1A1A`）而非白色。**

标题处理上：**尊重内容的原始语言。中文标题就直接用中文凸显（PingFang 加粗、加大），不要为了"潮"而自造英文标题或英文锚点。** 仅当内容本身确实是英文（品牌名、英文歌曲/作品名等）时才使用西文。

**核心特征：**
- 极浅薰衣草灰画布（`#F3F2F7`）+ 纯白圆角卡片，轻盈通透
- 清浅薄荷绿（`#4FE0B5`）为**主题主色**，薰衣草紫（`#9D8CF7`）为辅助色（次级强调，占比低于绿，不与绿渐变）
- **主题色克制**：单页面内仅关键操作/强调用薄荷绿，其余次要按钮用**深灰**（`#2A2A30`）
- **薄荷绿上的文字/图标用深灰 `#1A1A1A`，不用白色**（淡色需深字保对比）
- **标题尊重原文语言：中文标题直接凸显，不自造英文标题**
- **分级圆角**：胶囊（按钮/搜索/Chip）+ 16–20px 大圆角卡片 + 4–12px 小圆角小元素，按刻度分级取用、同级一致，而非一味全圆
- 顶部导航栏**通栏固定**（与页面背景同色的薰衣草灰、不悬浮、不玻璃）
- **底部导航采用 Material 3 navigation bar 模式**：实色容器表面 + 选中项薄荷绿浅底「药丸」指示器（active indicator）包裹填充图标，对比清晰
- **液态玻璃作为悬浮材质**：用于状态切换胶囊等真正悬浮于内容之上的元素
- 阴影极轻或无，靠填充色阶、明度差与圆角分层，扁平优先；但**描边需保证足够对比**（见 §2 描边色），不为了"轻"而牺牲可辨识度

## 2. 色彩方案与角色

### 主色（品牌绿）
青绿是整个风格的点睛色，清浅、明度偏高、通透，由浅到深构成一条可用于浅填充、悬浮态、主体、按下态的色阶。

- **薄荷绿 6 / Brand**（`#4FE0B5` · `rgb(79, 224, 181)`）：核心品牌色，用于**关键操作与强调**（主 CTA、关键控件、金刚区图标、底栏选中态的图标/文字）。
- **薄荷绿 5 / Hover**（`#6BE8C5` · `rgb(107, 232, 197)`）：悬浮/高亮态，比主色更亮。
- **薄荷绿 7 / Active**（`#2FCBA0` · `rgb(47, 203, 160)`）：按下/激活态，比主色更深。
- **薄荷绿 1 / Tint**（`#E9FBF5` · `rgb(233, 251, 245)`）：浅填充底色，用于选中标签、徽标背景、绿色文字的衬底。
- **薄荷绿 2 / Tint-2**（`#CDF5E7` · `rgb(205, 245, 231)`）：稍深的浅填充，用于卡片渐变收尾、领取类提示底。

> **薄荷绿配色铁律**：薄荷绿明度高，作为背景时其上的文字、图标一律使用深灰 `#1A1A1A`（或近黑），**严禁用白色**——白字在薄荷绿上对比不足、发虚、显廉价。

### 中性承重色（深灰）
深灰是与薄荷绿配套的「承重色」，承担**所有非关键的实色按钮与操作**，把主题绿让给真正关键的地方。

- **深灰 / Neutral Dark**（`#2A2A30` · `rgb(42, 42, 48)`）：次要实色按钮背景、非关键主操作。其上文字/图标用白色（深底，白字成立）。
- **深灰 Hover**（`#3A3A42` · `rgb(58, 58, 66)`）：悬浮态。
- 也可用主文字色 `#1A1A1A` 作更强的深色按钮底。

### 辅助色（薰衣草紫）
薰衣草紫是辅助点睛色，色相偏冷、温柔优雅，和画布的淡紫灰倾向天然呼应。它用于**次级强调与区分**——次要标签、第二类目的徽标等，避免界面单调。

- **薰衣草紫 6 / Secondary**（`#9D8CF7` · `rgb(157, 140, 247)`）：辅助色，用于次级强调标签、第二类目徽标。
- **薰衣草紫 5 / Hover**（`#B0A2F9` · `rgb(176, 162, 249)`）：悬浮/高亮态。
- **薰衣草紫 7 / Active**（`#8472E8` · `rgb(132, 114, 232)`）：按下/激活态。
- **薰衣草紫 1 / Tint**（`#EDEAFD` · `rgb(237, 234, 253)`）：浅填充底色。
- **薰衣草紫文字**（`#6A54D4` · `rgb(106, 84, 212)`）：浅紫底上的深紫文字，保证对比。

> **辅助色边界（重要）**：薰衣草紫是「辅助」，**不要用在表达品牌主题的位置**（主 CTA、主功能入口、底栏选中态、Logo 等只用薄荷绿）。紫色只承担「次级、第二类、区分」，整屏占比应明显低于绿。其上文字优先用深灰 `#1A1A1A` 或深紫 `#6A54D4`。薄荷绿与薰衣草紫**不要组合成渐变**，应并置使用。

### 中性色 · 背景与表面
- **薰衣草画布**（`#F3F2F7` · `rgb(243, 242, 247)`）：主页面背景，带极淡的紫灰倾向，是整体轻盈感的来源。
- **纯白表面**（`#FFFFFF`）：所有卡片、列表项、搜索框、固定顶栏的主表面色。
- **浅灰填充**（`#F0F0F3` · `rgb(240, 240, 243)`）：占位图、骨架屏、未加载封面、次级填充块。
- **分隔填充**（`#EBEBEF` · `rgb(235, 235, 239)`）：列表分组之间的间隙、轻分隔。

### 中性色 · 文字（分级文字角色）

参照成熟设计系统（如 Material 3 的 on-surface 角色族）的做法，文字按「强调层级」而非随意取色，每个层级有明确用途与最低对比要求。**强弱靠这套色阶 + 字重组合表达**，避免用大量字号跳跃。

- **主文字 / Text-1**（`#1A1A1A` · `rgb(26, 26, 26)`）：标题、主要内容、价格、列表主文字；**也是薄荷绿/薰衣草紫等淡色底上的文字与图标首选色**。对白底/浅底对比约 16:1，远超 AA。
- **次文字 / Text-2**（`#8A8A8F` · `rgb(138, 138, 143)`）：副信息、描述、分组标签、底栏未选中态。**仅用于 13px 以上或非关键信息**；对白底约 3.5:1，达到大字号/非文本 AA，但不满足小字正文 4.5:1——**正文长文本不要用 Text-2，改用 Text-1 或下方的 Text-body**。
- **正文增强 / Text-body**（`#5A5A62` · `rgb(90, 90, 98)`）：需要弱于主文字、但又是**成段正文/需保证可读**的场景（说明段落、表单说明）。对白底约 7:1，满足小字 AA，是 Text-2 在「正文可读性」上的补强档位。
- **占位 / 三级文字 / Text-3**（`#B5B5BA` · `rgb(181, 181, 186)`）：输入框占位符、`>` 箭头、最弱的装饰性信息。**对比不足，严禁用于承载真实信息的正文**，仅用于占位提示、disabled、纯装饰。
- **反白文字 / On-Dark**（`#FFFFFF`）：用于深灰、暖橙、近黑等**深底**之上；**不用于薄荷绿、薰衣草紫等淡色底**。
- **淡色底专用文字**：薄荷绿底→深灰 `#1A1A1A`；浅绿底（`#E9FBF5`）→深绿 `#2FCBA0`；浅紫底（`#EDEAFD`）→深紫 `#6A54D4`；金箔底→深金 `#9A7B3F`。这些是经过对比校准的「容器+文字」配对，**不要跨配对混用**（如浅绿底配中灰、深底配淡色文字）。

> **文字对比铁律**：① 常规正文（< 18px / < 14px 粗体）对其背景需 ≥ 4.5:1——这排除了 Text-2、Text-3 承载正文；② 大字号标题、非文本图标/边框需 ≥ 3:1；③ 任何「淡底」都必须配「深字」，任何「深底」才配「白字」，按上面的容器配对取用，不要凭感觉搭。

### 中性色 · 描边与分隔（足够对比）

> **描边对比原则**：过浅的描边等于没有描边。区分「装饰性分隔」与「功能性边界」两类，后者必须有足够对比才能被看见、被点。

- **功能性边界 / Outline**（`#C4C6CF` · `rgb(196, 198, 207)`）：线框按钮、输入框、可点卡片、需要被识别为「可交互边界」的描边。对白底约 1.9:1、对灰画布约 1.6:1——是保证边界**清晰可辨**的下限档位。**线框次按钮、输入框默认描边一律用 Outline，不要用更浅的分隔色**（旧版 `#E0E0E5` 偏浅，已上调为此值）。
- **装饰性分隔 / Outline-variant**（`#E0E0E5` · `rgb(224, 224, 229)`）：卡片内列表项之间的内分隔线、纯装饰性的轻分隔。这类**不承担「可交互边界」语义**，可以浅。
- **极淡分隔**（`#EBEBEF`）：通栏顶栏滚动时的发丝分隔、最弱的区隔。
- 选用规则：**能被点、被聚焦、被识别为控件边界的 → 用 Outline（`#C4C6CF`）**；**仅作视觉分组、不可交互的 → 用 Outline-variant（`#E0E0E5`）或更淡**。聚焦态描边转薄荷绿 `#4FE0B5` 并可加重到 1.5–2px。

### 语义色 / 情绪点缀色
这些色仅在特定运营、会员、榜单等情绪化场景出现，不参与常规界面。

- **暖橙 CTA**（`#FF7A2F` · `rgb(255, 122, 47)`）：运营弹层主按钮、营销强调、广告标识（足够深，白字可用）。
- **金箔起始**（`#F7E6BC`）与**金箔收尾**（`#EAD194`）：会员 / VIP 卡片的横向金色渐变。
- **金箔文字**（`#9A7B3F` · `rgb(154, 123, 63)`）：金色卡片上的深金文字。
- **强调品红**（`#E94C9B` · `rgb(233, 76, 155)`）：榜单/强调卡片背景。
- **强调草绿**（`#4FD98A` · `rgb(79, 217, 138)`）：榜单/强调卡片背景（与品红成对）。
- **促销蓝**（`#3A8EF0` · `rgb(58, 142, 240)`）：节点活动 Banner 主色。

### 功能/状态色
- **成功**（`#4FE0B5`，复用品牌绿）
- **警告**（`#FF7A2F`，复用暖橙）
- **危险/错误**（`#F5483B` · `rgb(245, 72, 59)`）

### 渐变系统
整体克制使用渐变，仅在少数场景出现：
- **金箔渐变（VIP）**：`linear-gradient(90deg, #F7E6BC 0%, #EAD194 100%)`，横向，用于会员卡。
- **领取/运营渐变**：`linear-gradient(180deg, #FFFFFF 0%, #E9FBF5 100%)`，由白到浅绿的纵向收尾，用于福利弹层背景。
- 强调卡片为**纯色块**（品红、草绿），不使用渐变。
- 薄荷绿与薰衣草紫**不组合为渐变**，应并置使用。

## 3. 液态玻璃（Liquid Glass）

这是本风格的「悬浮材质」，借鉴苹果 Liquid Glass 语言：让真正悬浮于内容之上的容器呈现半透明毛玻璃质感，背后内容被模糊、提亮透出，从而与下层内容产生通透层次。

### 适用范围（悬浮于内容之上的元素）
- **悬浮材质**：用于真正浮在内容之上的元素——状态切换胶囊、悬浮提示条、临时浮层等。玻璃材质让它们与下层内容拉开通透层次。
- **底部导航不用玻璃，改用 Material 3 navigation bar**：底部导航是常驻主导航，采用 MD3 模式的**实色容器表面 + 药丸指示器**（见 §5），对比清晰、选中明确——不再用半透明玻璃（玻璃底栏在复杂背景上易发灰、选中态可读性差）。
- **顶部导航栏不使用玻璃**：顶栏是**与背景同色（薰衣草灰）的通栏固定层**（见 §5、§6），不悬浮、不透明模糊、不另起色块。
- 不要用于常规白卡内容区——玻璃是「悬浮元素专属」，滥用会让界面发灰、失焦。

### 标准配方（浅色）
```css
background: rgba(255, 255, 255, 0.6);
backdrop-filter: blur(24px) saturate(180%);
-webkit-backdrop-filter: blur(24px) saturate(180%);
border: 0.5px solid rgba(255, 255, 255, 0.6);          /* 顶部高光描边 */
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.12),            /* 外部柔影，强化悬浮 */
            inset 0 1px 1px rgba(255, 255, 255, 0.7);  /* 内部高光，模拟玻璃边缘反光 */
```

### 要点
- `backdrop-filter: blur()` 是玻璃感的核心；`saturate(180%)` 让背后颜色更鲜活地透出，是「Liquid」通透感的关键。
- 半透明度建议 `0.55–0.7`：太透则文字不清，太实则失去玻璃感。
- 必配 `inset` 内高光 + 外柔影：内高光模拟玻璃边缘的光，外柔影强化「漂浮」。
- 玻璃层上的文字仍遵循文字色规范（主文字深灰）。
- 圆角：悬浮玻璃元素用胶囊（999px）或 20–28px 大圆角。

## 4. 排版规则

### 字体族
- **正文 / 标题 / UI（主力）**：`PingFang SC`，回退 `"Microsoft YaHei", "Hiragino Sans GB", -apple-system, system-ui, sans-serif`。承载所有中文标题与正文——**中文标题靠加大字号 + 加粗（600–700）凸显**。
- **西文（仅英文内容时）**：`Poppins` / `Montserrat`，回退 `-apple-system, Helvetica Neue, Arial`。**仅当内容本身是英文**（品牌名、英文作品名）时使用，不要为中文界面强加英文标题。
- 默认正文字号 **14px**，行高约 1.5。

### 层级

|------|------|------|------|------|------|

| 页面标题（中文） | PingFang SC | 18px | 600 | 1.25 | 导航栏标题 |
| 区块标题（中文） | PingFang SC | 16px | 600 | 1.30 | 内容分区标题 |
| 列表主文字 | PingFang SC | 15–16px | 500 | 1.40 | 设置项、条目主文字 |

### 原则
- **标题尊重原文语言**：中文标题直接用中文凸显（加大字号 + 加粗），不要自造英文标题或中英拼凑当锚点。西文仅用于真正的英文内容。
- **强弱靠字重与色阶，而非字号跳跃**：主次信息常用同号不同字重（500 vs 400）+ 主文字/次文字色阶区分。
- **价格与数值用重字重黑色**：价格、序号、关键数值用 700 粗体近黑色，制造视觉重量。
- **行高宽松**：正文 1.4–1.5，保持呼吸感。

## 5. 组件样式

### 按钮

> **总原则：克制用绿。** 单页面内薄荷绿按钮通常只出现 1 个（最关键的操作）。其余的次要/普通操作**并非一律深灰**——可按权重灵活选择：较重要的次操作用**深灰实色按钮**，较轻或并列的次操作用**线框（描边）次按钮**。两种次按钮可混用，目的都是把主题绿的信号价值留给最关键处，同时避免多颗高饱和实色按钮并列。

**主按钮 · 薄荷绿胶囊（Primary Pill）— 仅关键操作**
- 背景：薄荷绿（`#4FE0B5`）
- 文字/图标：**深灰（`#1A1A1A`）**，15–16px，字重 600 —— 不用白色
- 形态：全圆角胶囊（`border-radius: 999px`），高度约 48–52px
- 阴影：无或极轻（`0 4px 12px rgba(79,224,181,0.30)`）
- 悬浮：`#6BE8C5`；按下：`#2FCBA0`
- 全局最高优先级操作，整屏通常只出现一个

**深灰主按钮 · 特殊场景主操作（Neutral Dark Pill）**
- 背景：深灰（`#2A2A30`），文字/图标白色（深底白字成立）
- 形态：胶囊，高度同主按钮或略小；悬浮：`#3A3A42`
- 用于**一些特殊场景的主操作**——例如确认弹窗、活动弹层等，不会与薄荷绿主操作按钮同时出现在同一组按钮中

**线框按钮 · 轻量次操作（Outline Pill）**
- 背景：透明 / 白色，文字主文字色（`#1A1A1A`），字重 500
- 边框：`1px solid #C4C6CF`（功能性 Outline 描边，保证可辨识对比），胶囊（999px）
- 用于**较轻、或多颗并列的次操作**——例如「取消」「稍后再说」、列表里的常规操作、并列的多个次按钮
- 与深灰按钮的取舍：次操作要不要「实」一点，按其权重决定；同屏多个次操作时优先用线框，避免一堆深灰实色色块

**辅助按钮 · 薰衣草紫胶囊（Secondary Pill）— 仅需紫色语义时**
- 背景：薰衣草紫（`#9D8CF7`）或浅紫底（`#EDEAFD`），文字深灰或深紫，不用白色
- 仅当次级动作本身需要紫色语义标识时使用；否则次操作优先深灰/线框

**暖橙运营按钮（Promo CTA）**
- 背景：暖橙（`#FF7A2F`），文字白色；胶囊、通栏，仅用于运营/福利弹层

**图标圆形按钮（Icon Circle）**
- 背景：白色 / 深灰 / 薄荷绿（关键时），正圆，尺寸 40–56px
- 薄荷绿底上的图标用深灰 `#1A1A1A`；白底上的图标用深灰；深灰/近黑底用白色图标

### 卡片与容器
- 背景：纯白（`#FFFFFF`）
- 圆角：列表卡/内容卡 **16px**；大封面卡/Banner **20px**；小封面/缩略图 **8–12px**；角标/徽标 **4–6px**。**按内容尺寸选对应档位的圆角，不要把小元素也做成最大圆角**。
- 边框：通常无边框，靠白底与灰画布的对比分层；若卡片本身可点（整卡作为按钮），用 `1px solid #C4C6CF` 功能性描边明确其可交互边界
- 阴影：默认无；需要悬浮感时用极轻柔阴影（`0 2px 12px rgba(0,0,0,0.04)`）
- 内边距：约 16px
- **分组列表卡**：同一分组的多个列表项合并进一张白色圆角卡，项间用 `1px` 浅色内分隔线（装饰性分隔 `#E0E0E5`），分组之间用画布间隙分隔（约 24px）。

### 顶部导航栏（通栏固定 · 与背景同色）
- **通栏固定**：横贯整个屏宽，固定在顶部，**不悬浮、不留边、不使用液态玻璃**。
- 背景：**与页面背景画布同色（薰衣草灰 `#F3F2F7`）**——让导航栏与内容区融为一体、无明显色块或白条感，通常**不需要分隔线**，靠留白自然过渡。若内容滚到栏下需要区分，可在滚动时加一条极淡的 `1px` 分隔线（`#EBEBEF`），默认保持无缝。
- 结构：左返回/标题（中文标题就用中文）、中间标题（PingFang 18px / 600）、右功能图标。
- 内容区在其下正常排布（顶部留出导航栏高度的安全距），导航栏不参与滚动、始终可见。

### 底部导航栏（Material 3 Navigation Bar · 标志性组件）

底部主导航采用 **Material 3 navigation bar 模式**：实色容器表面 + 选中项「药丸」指示器（active indicator），对比清晰、选中态一眼可辨。这取代了早期的半透明玻璃底栏（玻璃在复杂内容上易发灰、选中可读性差）。

- **形态**：贴底通栏（也可左右留 12–16px 做悬浮卡式，但材质仍为实色而非玻璃），高度约 64–80px（含标签）。圆角：贴底通栏可不加圆角或顶部 16px；悬浮卡式用 20–28px。
- **容器表面**：实色，用比画布略深一档的中性表面（`#F0EFF4` 或纯白 `#FFFFFF`），叠一层极轻阴影（`0 -1px 8px rgba(0,0,0,0.04)` 或 `0 2px 12px rgba(0,0,0,0.06)`）以与内容区分离；**不用半透明玻璃**。
- **内容**：3–5 个 Tab，每个为 **图标 + 中文标签**（标签 11–12px，置于图标下方）。
- **选中态（用药丸指示器）**：① 图标外包裹一颗**薄荷绿浅底药丸**（active indicator）——胶囊形（约 56×30px），底色用浅绿 `#E9FBF5` 或品牌绿 `#4FE0B5`；② 药丸内图标切换为**填充态（实心）**，色用深绿 `#2FCBA0`（浅绿药丸上）或深灰 `#1A1A1A`（品牌绿药丸上，遵守淡底深字）；③ 标签转主文字色并**字重加粗**（500 → 600–700）。药丸出现可带轻微缩放/淡入过渡（见 §动效）。
- **未选中态**：无药丸；图标为**线性（描边）态**，图标与标签用次文字灰（`#8A8A8F`），标签常规字重。
- **触控**：每个 Tab ≥ 48×48px（点击热区，对齐 MD3 触控目标）。
- **与玻璃的关系**：底部导航是常驻主导航，用实色 MD3 navigation bar；液态玻璃留给**真正悬浮于内容之上的临时元素**（状态切换胶囊、浮层）。

### 列表项
- 高度：约 52–56px；左侧主文字（15–16px / 500），右侧次值或 `>` 箭头（`#B5B5BA`）
- 开关项：右侧 iOS 风格 Switch，开启态填充薄荷绿
- 点击态：浅灰填充（`#F7F7FA`）

### 输入 / 搜索框
- 背景：白色 或 浅灰填充（`#F0F0F3`）
- 形态：胶囊（`border-radius: 999px`），高度约 36–40px
- 边框：需要明确边界时用 `1px solid #C4C6CF`（功能性 Outline）；纯填充式（灰底无框）可不描边
- 左内放搜索图标（灰），占位文字 `#B5B5BA`；聚焦时边框或图标转薄荷绿 `#4FE0B5`（可加重到 1.5px）

### 标签 / Chip
- 背景：白色；选中态浅绿底（`#E9FBF5`）+ 绿字，或浅紫底（`#EDEAFD`）+ 紫字
- 文字：主文字色，13px；形态胶囊，内边距约 `6px 14px`

### 角标 / Badge
- 形态：小圆角矩形（4px）或胶囊
- 示例：状态绿底绿字（`#E9FBF5` / `#2FCBA0`）；强调紫底紫字（`#EDEAFD` / `#6A54D4`）；中性灰底灰字

### 功能入口网格（金刚区）
- 横向 4–5 列；**所有图标统一使用薄荷绿**（线性图标 `#2FCBA0`，或浅绿圆角底 `#E9FBF5` + 绿图标）——金刚区是同级入口的集合，**不区分主次，保持视觉一致**，不要让其中某些变深灰、某些变绿造成杂乱。下方文字 13px 主文字色；图标约 24px。
- 注：金刚区图标是「同一组功能入口」，与"按钮要克制用绿"是不同语境——这里的一致性优先于主题色克制。

### 强调/榜单卡片
- 大圆角（16–20px）纯色块卡；成对使用品红（`#E94C9B`）与草绿（`#4FD98A`）
- 内容：白色粗体大标题 + 黑色圆形控件 + 底部嵌入小缩略图

## 6. 布局原则

### 间距系统
- 基础单位：4px；常用刻度：4 / 8 / 12 / 16 / 20 / 24 / 32px
- 页面左右安全边距：**16px**；卡片内边距：16px；分组卡间隙：24px；区块标题与内容间隔：12px

### 移动端结构
- 顶部：状态栏（系统）+ **通栏固定的导航栏**（约 44–48px，**背景与画布同色 `#F3F2F7`、无缝融入**），始终可见、不悬浮、不玻璃、不另起色块。
- 内容区：可滚动卡片流，背景薰衣草灰（`#F3F2F7`），卡片纯白浮于其上；顶部留出导航栏高度的安全距。
- 底部：**Material 3 导航栏**，贴底通栏（或悬浮卡式但实色非玻璃），实色容器 + 选中药丸指示器；内容区底部预留约 90–120px 安全距，避免被导航栏遮挡。

### 圆角刻度（分级取用 · 同级一致）

圆角是「分级系统」而非「越大越好」。每个尺寸/层级的元素用对应档位，并保持同级一致；**不要把小元素也做成最大圆角，也不要用尖角破坏圆润人格**。

- 小（4–6px）：角标、徽标、密集信息的小色块
- 中（8–12px）：小缩略图、封面、输入框（方形场景）、列表项内的小图标容器
- 大（16px）：列表卡、内容卡
- 超大（20–28px）：Banner、大封面卡、运营弹层、悬浮玻璃元素、悬浮卡式导航
- 胶囊（999px）：按钮、搜索框、Chip、导航栏选中药丸
- 正圆（50%）：圆形控件、头像、功能圆钮

> 选取原则：**圆角半径与元素尺寸成正比**——元素越小，圆角越小，否则小元素会显得过度膨胀、丢失信息密度。表格、密集列表、贴边/通栏元素等场景，恰当的小圆角甚至直边更利落。

### 留白哲学
- **白卡浮于灰底**：用画布灰与卡片白的明度差替代边框和阴影来分层。
- **玻璃悬浮于内容**：液态玻璃材质用于真正悬浮的元素（状态胶囊、浮层），与下层内容拉开通透层次。
- **分组即留白**：列表用「分组合卡 + 组间灰隙」组织。
- **点睛靠留白与克制**：大面积中性留白 + 主题色克制，薄荷绿才能成为视线焦点。

## 7. 深度与层次

| 层级 | 处理方式 | 用途 |
|------|----------|------|
| 平面（L0） | 无阴影、无边框 | 画布背景、内联文字 |
| 卡片（L1） | 白底浮于灰画布，靠明度差分层 | 列表卡、内容卡（默认） |
| 固定（L1.5） | 与背景同色的通栏固定层，无缝过渡（可选极淡分隔线） | 通栏固定顶部导航栏 |
| 导航（L2） | 实色容器表面 + 极轻阴影（`0 -1px 8px rgba(0,0,0,0.04)`） | Material 3 底部导航栏 |
| 轻浮（L2） | `0 2px 12px rgba(0,0,0,0.04)` | 需要轻微悬浮感的卡片 |
| 玻璃（L3） | 液态玻璃材质（半透明 + `blur(24px) saturate(180%)` + 内高光 + 外柔影） | 悬浮于内容之上的元素（状态胶囊、浮层） |
| 强调（L4） | `0 4px 12px rgba(79,224,181,0.30)`（品牌绿光晕） | 主 CTA 胶囊按钮的可选投影 |

**阴影哲学**：扁平优先。常规分层靠「白卡 + 灰底」明度对比；顶部导航是与画布同色的固定层；底部导航是实色 MD3 navigation bar（极轻阴影分离）；液态玻璃用于真正悬浮的元素；主按钮可选地带一圈品牌绿柔光。**但分层「扁平」不等于边界「模糊」——可交互边界仍需用足够对比的功能性描边（见 §2）。**

## 8. 应做与禁忌

### Do
- 用薰衣草灰（`#F3F2F7`）做画布、纯白做卡片，靠明度差分层
- **标题尊重原文语言：中文标题用中文加大加粗直接凸显**
- **顶部导航栏通栏固定、与背景画布同色（薰衣草灰）**，无缝融入、始终可见
- **主题色克制（按钮场景）**：单页面只在 1～2 个关键操作/强调处用薄荷绿按钮；其余次操作按权重用深灰实色或线框（描边）次按钮，二者可混用
- **金刚区图标统一用薄荷绿**——同级入口不分主次，保持视觉一致（与"按钮克制用绿"不同语境）
- **底部导航用 Material 3 navigation bar**：实色容器 + 选中项薄荷绿浅底药丸（active indicator）包裹填充图标 + 标签加粗；未选中=线性图标 + 中灰
- **薄荷绿底上的文字与图标用深灰 `#1A1A1A`**，保证对比与质感
- 薄荷绿（`#4FE0B5`）作主题主色、薰衣草紫（`#9D8CF7`）仅作辅助色，二者并置不渐变、紫占比低于绿
- 液态玻璃用于**真正悬浮于内容之上的元素**（状态切换胶囊、浮层）
- **圆角分级取用、同级一致**：按钮/搜索/Chip 用胶囊（999px）；卡片 16px、Banner 20px；小元素 4–12px——不要一味全圆，也不要用尖角
- **可交互边界用足够对比的功能性描边**（Outline `#C4C6CF`）；装饰性分隔才用浅色（`#E0E0E5`）
- **文字按分级角色取用**：正文 ≥4.5:1（用 Text-1 / Text-body），次要信息用 Text-2，占位/箭头才用 Text-3
- 列表用「分组合卡 + 组间灰隙」组织
- 运营/会员/榜单场景才使用暖橙、金箔、品红/草绿等情绪色点缀

### Don't
- **不要为中文界面自造英文标题/英文锚点**——中文内容就凸显中文
- **不要让顶部导航栏悬浮、加玻璃或另起白色/实色色块**——它与背景同色、无缝融入
- **不要在按钮场景整页大量使用主题绿**——关键操作之外用深灰或线框；但金刚区图标是例外，应统一用绿
- **底部导航用 MD3 药丸指示器表达选中**——别再用「裸图标变色」的弱选中，药丸 + 填充图标 + 标签加粗的对比更清晰
- **不要在薄荷绿或薰衣草紫上用白色文字/图标**——淡色 + 白字对比不足、发虚
- **不要在主题信号位（主 CTA、底栏选中、Logo）用辅助紫或绿紫混用**
- **不要把薄荷绿和薰衣草紫混成渐变**——明度接近会显浑浊，应并置
- 不要把液态玻璃用在常规白卡内容区、顶栏或底部导航——玻璃只给真正悬浮的元素
- **不要一味把所有元素都做成最大圆角**——圆角分级、与元素尺寸成正比；小元素用小圆角，但也不要用尖角（< 4px）破坏圆润人格
- 不要用纯黑（`#000`）做文字，主文字用柔黑（`#1A1A1A`）
- 不要在常规界面引入暖橙/金箔/品红——情绪色仅限运营、会员、榜单
- **不要用过浅的描边做可交互边界**——线框按钮/输入框/可点卡片用 Outline `#C4C6CF`，浅色（`#E0E0E5`）只用于装饰性分隔
- **不要用次文字灰（`#8A8A8F`）/占位灰（`#B5B5BA`）承载小字正文**——正文对比需 ≥4.5:1，改用 Text-1 或 Text-body `#5A5A62`
- 不要让画布变成纯白——薰衣草灰是轻盈感的底色

## 9. 响应式行为

本风格面向**移动端竖屏**为主（典型 375–430px 宽）。

### 适配要点
- 安全边距固定 16px，卡片宽度 = 屏宽 − 32px
- 顶部导航栏通栏固定，宽度撑满屏宽；内容区顶部留出其高度的安全距
- 功能入口网格按屏宽等分（4–5 列），图标尺寸固定、间距弹性
- 横向滚动模块：卡片定宽，超出部分横滑，右侧露出半张暗示可滑动
- Banner / 大封面卡：宽度撑满安全区
- 底部 Material 3 导航栏：贴底通栏撑满屏宽（或悬浮卡式左右各留 12–16px）；内容区底部留 90–120px 安全距

### 触控目标
- 按钮、列表项、底部导航 Tab 最小可点区域 ≥ 48×48px（对齐 Material 3 触控目标）
- 圆形控件 ≥ 40px；Chip 保证 `6px 14px` 以上内边距

## 10. Agent 提示指南

### 快速色值参考
- 品牌主色（关键操作 / 强调 / 金刚区图标 / 底栏选中药丸）：薄荷绿 `#4FE0B5`（其上做按钮/药丸背景时文字图标用深灰 `#1A1A1A`；做图标/文字本身的强调色时用深绿 `#2FCBA0`）
- 承重次操作（较重要的非关键实色按钮）：深灰 `#2A2A30`（白字）
- 轻量次操作：白色/透明 + `1px solid #C4C6CF` 功能性描边线框按钮
- 辅助色（仅次级强调，占比低于绿、不与绿渐变）：薰衣草紫 `#9D8CF7`（其上文字用深灰或深紫 `#6A54D4`）
- 页面背景：薰衣草灰 `#F3F2F7`；卡片表面：纯白 `#FFFFFF`；底部导航表面：`#F0EFF4` 或纯白
- 文字分级：主文字 `#1A1A1A`（标题/正文/淡底字）；正文增强 `#5A5A62`（成段正文需弱于主文字时）；次文字 `#8A8A8F`（≥13px 非关键）；占位/箭头 `#B5B5BA`（不承载正文）
- 描边分级：功能性边界（可交互）`#C4C6CF`；装饰性分隔 `#E0E0E5`；极淡分隔 `#EBEBEF`；聚焦态转薄荷绿 `#4FE0B5`
- 液态玻璃（悬浮元素）：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(24px) saturate(180%)` + 内高光 + 外柔影
- 运营 CTA：暖橙 `#FF7A2F`（白字）；VIP 渐变：`linear-gradient(90deg,#F7E6BC,#EAD194)`；强调品红/草绿：`#E94C9B` / `#4FD98A`

### 示例组件提示词
- 「做一个移动端页面，主题色克制：整页只有最关键的『立即开始』按钮用薄荷绿（`#4FE0B5`，深灰字 `#1A1A1A`，胶囊 999px）；并排的次操作按权重选择——较重的用深灰实色按钮（`#2A2A30`，白字），较轻或多个并列的用白色 + 中性描边的线框次按钮，不要再用第二颗绿。」
- 「做一个通栏固定的顶部导航栏：背景与页面画布同色（薰衣草灰 `#F3F2F7`），横贯屏宽、固定在顶部不悬浮、不加玻璃、不另起白色或实色色块，与内容无缝融入；左侧返回箭头，中间中文标题（PingFang 18px / 600），右侧一个功能图标。」
- 「页面主标题用中文直接凸显：PingFang 24–28px、字重 700、柔黑 `#1A1A1A`——不要加英文副标题或英文锚点。」
- 「做一个 Material 3 风格的底部导航栏：实色容器表面（`#F0EFF4` 或纯白）+ 极轻阴影分离，5 个 Tab（图标 + 中文标签 11–12px）；**选中态用薄荷绿浅底药丸指示器**——选中项图标外包一颗胶囊形浅绿药丸（`#E9FBF5`，约 56×30px），药丸内图标为填充态深绿（`#2FCBA0`），标签转主文字色并加粗（600）；未选中为线性图标 + 中灰（`#8A8A8F`）、无药丸。每个 Tab 点击热区 ≥ 48×48px。」
- 「做一个金刚区功能入口网格：5 个入口图标**统一用薄荷绿**（线性 `#2FCBA0` 或浅绿圆角底 `#E9FBF5` + 绿图标），同级入口不分主次、保持视觉一致；下方中文标签 13px。」
- 「做一个强调/榜单卡片：16px 圆角纯色块，成对用品红 `#E94C9B` 与草绿 `#4FD98A`，标题用中文加粗。」
- 「注意圆角分级：卡片 16px、Banner 20px、按钮/搜索/Chip 胶囊、小缩略图/角标 8–12px / 4–6px——按元素尺寸取对应档位，不要全做成最大圆角。」
- 「描边要有对比：线框按钮、输入框、可点卡片用 `1px solid #C4C6CF`（看得见的功能性边界）；卡片内列表分隔线才用浅色 `#E0E0E5`。」
- 「文字按层级取色：标题/正文用主文字 `#1A1A1A`，成段说明用 `#5A5A62`，次要副信息用 `#8A8A8F`，占位符/箭头才用 `#B5B5BA`——小字正文不要用次文字灰，对比不足。」

### 迭代指南
1. 一次只聚焦一个组件。
2. 引用具体色名 + 色值——「用薄荷绿 `#4FE0B5`，其上文字用深灰 `#1A1A1A`」。
3. 标题先确认语言：中文内容就用中文凸显，不要自造英文。
4. 检查主题色用量：单页面绿**按钮**通常只 1 个，其余次操作用深灰或线框；但金刚区图标统一用绿、底栏选中药丸用绿，属正常。
5. 顶栏与背景同色无缝固定；底部导航用实色 MD3 navigation bar + 选中药丸（非玻璃）；液态玻璃只给真正悬浮的元素（状态胶囊、浮层）。
6. 明确圆角形态并分级——按钮/搜索框/Chip 说「胶囊 999px」，卡片说「16px / 20px」，小元素说「8–12px / 4–6px」；不要一味全圆。
7. 检查描边对比与文字层级——可交互边界用 `#C4C6CF`，分隔线才用浅色；小字正文用主文字色，不用次文字灰承载。
8. 情绪色（橙/金/品红）只在运营、会员、榜单场景出现，需显式说明场景。
