# 薄荷青绿 · 轻盈活力风格（Mint Vibe）设计系统

[DESIGN.md](./DESIGN.md) 是一套面向 AI Agent 优化的**移动端视觉风格**规范，提炼自一组清爽、年轻、活力的界面。它不绑定任何具体产品或品牌，仅表达一种可复用的设计语言，适用于在线 AI 工具（Stitch、AI Studio、Coze 等）与本地 AI 编程工具快速生成符合该风格的移动端界面。

## 文件

| 文件 | 描述 |
|------|------|
| `DESIGN.md` | 完整的设计系统文档（9 个章节），中文版 |
| `preview.html` | 交互式设计 token 目录（浅色模式） |
| `preview-dark.html` | 交互式设计 token 目录（深色模式） |
| `example-mobile.html` | 用本设计系统拼装的完整移动端示例页面（效果验证） |

## 使用方式

将 [DESIGN.md](./DESIGN.md) 复制到你的项目中，或直接粘贴到 AI 工具的上下文中，告诉 AI"按照这个设计系统帮我生成页面"即可。

所有颜色均以直接 hex / rgb 色值提供，无需依赖 CSS 变量或特定框架环境，任何 AI 编程工具都能直接使用。

## 设计特征

- **品牌色**：春日薄荷绿（`#2DE0A6`），单一高饱和点睛色，年轻明快
- **风格**：轻盈、通透、活泼，面向年轻用户的移动端内容消费体验
- **画布**：极浅薰衣草灰（`#F3F2F7`）+ 纯白圆角卡片，靠明度差分层
- **字体**：Poppins 西文 Wordmark（标题锚点）+ PingFang SC 中文正文，14px 默认
- **形态**：全局胶囊按钮 + 16–20px 大圆角卡片，零尖角
- **悬浮条**：标志性悬浮底部条（圆 + 胶囊 + 圆三段式）
- **深度**：扁平优先，阴影仅用于真正悬浮的元素
- **情绪色**：暖橙（运营）、金箔渐变（VIP）、品红/草绿（榜单）做场景化点缀

## 预览

- 在浏览器中打开 `preview.html` 或 `preview-dark.html`，查看色板、字体层级、按钮、输入框、列表、Chip、悬浮条、阴影、圆角与间距的可视化展示。
- 打开 `example-mobile.html` 查看用本设计系统拼装的完整移动端页面（音乐发现首页 + 底部播放器），用于验证整体风格落地效果。

## 适用场景

- 移动端内容消费类 App（音乐、音频、社区、电商等）
- 面向年轻用户、强调轻盈活力的产品
- 需要清爽留白 + 单一高饱和点睛色的界面体系
